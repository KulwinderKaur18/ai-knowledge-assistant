# DATA NOTE — corpus/

Every document in this directory is **synthetic sample data** written by hand
for the sole purpose of demonstrating this software. "Northwind Outfitters" is
a fictional company; all policies, figures, email addresses (@northwind.example),
and procedures are invented and describe nothing real.

Each document also carries a notice blockquote at the top, which the ingestion
code strips before chunking.

Do not treat this corpus as factual information about any real organization.
